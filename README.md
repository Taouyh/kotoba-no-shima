# ことばの島 · Kotoba no Shima

为自己学习日语做的轻量闯关游戏。用短关卡、主动回忆和间隔复习，从假名走向 N4 目标课程，再进入介护特定技能日语入门。中文界面，支持电脑和手机浏览器。

应用日语名为「ことばの島」（语言之岛）。网页版、Windows 和安卓的应用名一致，学习讲解保留中文。

[在线游玩](https://taouyh.github.io/kotoba-no-shima/) · [下载安装版](https://github.com/Taouyh/kotoba-no-shima/releases) · [分享与打包说明](docs/DISTRIBUTION.md)

网页版无需账号或安装，首次加载后可离线使用，也可通过浏览器菜单安装为 PWA。安装版将页面和题库放在本地。每位新玩家从空进度开始；源码、网站和安装包不包含作者的学习记录。

## 启动

Windows 可直接双击 **`start-game.cmd`**，会启动游戏并自动打开浏览器。游玩时保持启动窗口打开，结束后在窗口按 Ctrl+C。默认使用固定地址，避免端口变化导致看不到原有进度。

需要 Node.js 20.19+ 或 22.12+（推荐 Node 24 LTS）和 npm。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 **http://127.0.0.1:5173**。已经安装过依赖时，只需要 `npm run dev`。

体验离线和安装功能，请使用正式构建预览：

```bash
npm run build
npm run preview
```

默认打开 **http://127.0.0.1:4173**。首次联网访问并完成缓存后，可以离线重新打开。应用需通过 HTTP 服务访问，不能直接双击 `index.html`。

开发地址、预览地址和将来的线上地址属于不同的网站存储空间。切换地址前，在「小岛设置」导出进度，再在新地址导入。

## 保留的假名基础功能

- **六个自由探索区域**：平假名清音与拨音、浊音与半浊音、片假名、拗音、拍感、高低音基础。
- **214 个假名学习项**：平假名和片假名各 46 个基本假名、25 个浊音 / 半浊音、36 个拗音组合。包括较少见的ぢゃ等组合及对应片假名。
- **16 道发音概念题**：长音、促音、拨音、拗音拍数、东京日语词重音与句调入门。
- **每日 12 题小冒险**：优先练平假名浊音和片假名；少量新字先认识，再交错回忆。
- 看字输入罗马字、四选一、设备声音可用时的听音辨认。接受常见罗马字与输入法别名，例如 shi / si、ぢ的 ji / di、づ的 zu / du。
- 提示、迟疑标记、答题解释、拍格和高低示意图。
- 本地保存、复习到期时间、学习手帐、连续学习日和纪念章。
- JSON 备份导出、校验后确认导入、二次确认清空。
- 响应式布局、键盘操作、PWA 离线页面与题库缓存。

## 如何练习

1. 第一次直接点「开始今日冒险」，认识少量浊音和片假名。
2. 看字输入读音。想不起来再看提示；也可切换选项。
3. 「想了一下」可主动标记迟疑；反应时间只作辅助，不作发音评分。
4. 在「五十音图」查阅字形、读音，点击单个字开启同组练习。
5. 有到期内容时，进入复习。长音、促音等在「节奏海岸」用词语与拍格练习。
6. 定期导出备份，尤其是在换浏览器或清除网站数据前。

已有假名基础后，在首页切换「N4 生活群岛」。可以分别从汉字、词汇、会话、语法、阅读五条小径的首站开始，不必等汉字全部学完。介护区也有独立的语言与技能概念入口。

## 地图、星星与贝壳

- 首星：完成至少 6 题（小关卡按实际数量）、正确率达到 60%。获得此星即可解锁同一小径的下一站。
- 第二星：已有首星，且探索至少 60% 的不同学习项。
- 第三星：已有首星，且至少 60% 的不同学习项经间隔复习达到熟练。
- 「探索」「解锁」和「熟练」分别显示，地图星星不是考试合格判定。
- 完成至少 6 题的一轮练习，获得 5 枚贝壳加答对题数（最多加 12），每天最多发放 60 枚。同一轮不可重复领取，中途退出不发奖励，但已答题目会保存。
- 在收藏小屋兑换后，选择位置再摆放。同一件装饰移动到新位置后，会从旧位置移走；收回不会从收藏中删除。贝壳没有付费或交易功能。

## 学习记录与复习规则

学习记录保存在当前浏览器的 IndexedDB 中，不需要账号，不上传答题记录。平假名 / 片假名、看字 / 听音、词义理解、概念题分别记录。新旧课程共用到期复习入口。

答错、用过提示或明显迟疑的内容会安排约 5 分钟后的复习。独立且顺畅的正确回答，按阶段安排约 1、3、7、14、30 天后的复习。阶段提升至少间隔 6 小时，同一天短时间反复刷题不会直接达到「熟练」。达到第三阶段才计入熟练。

这是一个透明、简单的规则调度器，不是经过个体拟合的 FSRS，也不代表已经客观测量长期记忆。假名的反应时间阈值为 10 秒，新词认读为 30 秒，短语和阅读等为 90 秒；输入速度会影响它，浏览器标签页在后台的时间会扣除。学习手帐最多保留 20,000 条最近答题记录、10,000 轮关卡记录。

备份格式升级为 v2，包含贝壳、装饰、摆放和收藏；仍接受 v1 文件。设置页可以导出首次升级前的快照。清空小岛会一并清除该快照。备份导入经过结构和已知条目校验，并在确认后替换当前进度。

## 音频当前状态

**当前仍未内置经逐条核对的日语真人录音。**

- 假名参考音使用浏览器 `speechSynthesis` 提供的日语声音。设备没有日语声音时，听音关卡不可用，其他练习照常可用。
- 可在「小岛设置」选择和试听声音。系统可能需要安装日语语音包；在线声音也可能需要联网。
- 合成语音辅助认读，不能作为发音或声调正确性的裁判。当前没有麦克风评分。
- 高低音关卡中的声音是明确标注的高低纯音，用于示意走势，不冒充日语真人音频。
- `src/lib/audio.ts` 的 `recordings` 映射预留了核对录音入口。后续可添加有适当授权的音频文件，按学习项 ID 绑定，并扩展 PWA 的音频缓存。

课程视频尚未完成分 P 和字幕核对，题目不能视为与出口仁老师的视频逐节对应。视频和 Tofugu 的音轨、插图、联想图片未被复制到项目。

    Collection.tsx         小屋场景、装饰商店和旅行护照
  data/
    curriculum.ts          旧版假名、别名和发音概念题

    care.ts                介护术语、声かけ、文书与概念
    sources.ts             来源链接与核对日期
    game.ts                装饰元数据和默认小屋

## 分享与安装版

主分支推送后由 GitHub Actions 测试、构建并发布到 GitHub Pages。Vite 使用相对资源路径，支持项目子目录。首次换到线上地址时，在旧地址导出备份，在新地址导入；设备之间不自动同步进度。

Windows 使用 Tauri 2 和系统 WebView2，安卓使用 Capacitor 8 和系统 Android WebView，共用 React、TypeScript 与 IndexedDB 游戏代码。Windows 安装包使用 NSIS，只在系统缺少 WebView2 时下载运行环境；安卓安装包使用固定签名密钥，支持后续同签名升级。没有内置浏览器、Node.js、托盘常驻进程或自动更新服务。

`.github/workflows/installers.yml` 在版本标签推送时生成 Windows x64 安装程序和安卓 APK，全部成功后发布预览 Release。Android 需要配置签名 Secrets；Windows 当前没有商业代码签名证书。详见 [打包与发布说明](docs/DISTRIBUTION.md)。
