## 词条合成语音读法修复

用户反馈「五月」显示「ごがつ」，但设备把汉字合成为「さつき」。现在汉字与词汇练习优先把该词条标注的假名传给设备语音，避免设备自行选择其他读法；完整句子继续使用原文，以保留助词与上下文。按词条 ID 匹配的录音仍优先播放。

- `npm test`：35 项通过，新增 11 项验证「五月」「十分」「一日」、介护词汇、句子与假名、声音缺失及录音优先逻辑。
- `npm run build`：通过。
- `npm run test:e2e -- tests/audio.spec.ts --workers=1 --max-failures=1`：1 项通过，在真实浏览器打开「五月」词条并点击播放，确认合成语音收到「ごがつ」。此检查使用模拟设备声音，验证传入读音，未试听用户设备的实际音质或声调。
