# 内容与扩展约定

## 课程内容

`src/data/curriculum.ts` 是课程数据入口。基本假名和浊音先定义平假名，再转换为片假名；转换只处理平假名字符，不修改分隔符和汉字。

每个 Kana 有稳定 `id`、字形、罗马字读音、输入别名、文字体系、类别、所在行和提示。ID 是学习记录的外键，发布之后不要直接改名；需要改名时增加显式迁移。

`h-` 为平假名，`k-` 为片假名。拗音作为完整组合记录。现代常用表的清音与拨音合计各 46 个；不把长音和促音误当成独立的五十音表格行。

## 读音与输入法

- 判读音时接受常见读音拼写，不把日语输入法的拼写当作唯一标准。
- ぢ / ヂ通常接受 ji、zi、di；づ / ヅ接受 zu、du、dzu。
- を / ヲ作为助词通常读 o，同时接受 wo。
- 听音题不会把通常同音的じ和ぢ、ず和づ、或お和を放在同一组选项里；干扰项之间也去除同音。
- 部分假名单独输入合成语音时可能读出不自然的音。加入正式录音后需逐项核对，不能仅凭文字到语音成功调用就视为教学音频合格。

## 发音概念

概念题和假名共用关卡外壳，但用独立 ID 和 `concept` 方向保存。每道题有问题、显示词语、唯一答案、解释，以及可选拍格、高低序列、对比词。

例子包括：

- きゃ一拍，きや两拍；きょう两拍。
- おばあさん五拍；がっこう四拍；コーヒー四拍。
- 促音的实现取决于后续辅音；不能统一解释成「完全静音」。
- 东京日语示例中，雨为高低，飴为低高；桥接助词用于展示平板和尾高的差异。
- 高低重音与句子语调分别讲解，不把单个假名赋予固定声调。

高低图仅为教学示意。真实语流受地区、语境和句子结构影响，后续增加词条时需要记录方言、来源和经核对的读音。

## 加入录音

1. 获取有明确使用与再分发许可的录音，核对发音并记录来源和许可。
2. 将音频放在 `public/audio/`。
3. 在 `src/lib/audio.ts` 的 `recordings` 中添加学习项 ID 到相对路径的映射，例如 `'h-が': 'audio/h-ga.mp3'`。
4. 在 VitePWA 的缓存策略中显式加入音频；较大内容使用按需下载，不强制缓存全部内容。
5. 扩展语音可用性检查，使有本地录音的题可在没有设备日语声音时开课。目前听音入口仍以设备声音是否可用为条件。
6. 为长短音、促音等准备完整词语的录音，避免生硬拼接单字音。

不要直接复制课程视频音轨或第三方联想插图到公开仓库。

## v0.2：扩展内容

统一入口为 `src/data/catalog.ts`，内容共 1,332 项。`lessons.ts` 定义 31 个新关卡与前置关系，`study-types.ts` 定义数据结构。

- `kanji.ts`：314 个不同汉字，配代表词、读音和词义。重复代表词不会重复增加汉字数。
- `words.ts`：614 个生活与学习词汇。
- `phrases.ts`：90 个日常交流表达及语境说明。
- `grammar.ts`：60 道原创语法填空，以含义提示限制目标用法，避免只凭空缺猜语义。
- `reading.ts`：16 道原创生活短阅读。
- `care.ts`：160 个介护术语、40 个声かけ表达、10 道文书题和 28 道基础概念题。
- `sources.ts`：官方资料入口、版本说明和核对日期。

JLPT 未公布固定完整清单，数据分组属于本项目的教学组织，涵盖基础复习、N4 目标扩展及少量衔接词。不把每个条目标成「官方 N4 指定词」。介护原始教材未全文复制到项目，游戏题为自主整理和原创练习。

每个学习项使用稳定 ID。新增时不要改动旧 ID，也不要用会随排序改变的数组序号作为 ID。语法条目 ID 包含句型名称；阅读和场景使用显式短 ID。增加同形多音词时，用不同 ID，并给认读题提供词义语境。

认读和意思理解分别保存；语法、阅读和介护概念用 `concept` 方向保存。词组目前优先练整体意思。罗马字是输入辅助，不代替假名；已加入有限的同义读音变体，例如「毎年」的まいとし／まいねん、「十分（十分钟）」的じゅっぷん／じっぷん。新增变体后，出题时也要排除多正确答案。

## v0.2：地图与收藏

`src/lib/game.ts` 处理星星、解锁、奖励、兑换和摆放，`src/data/game.ts` 定义装饰和四个位置。展示组件分别为 `Journey.tsx` 和 `Collection.tsx`，装饰为原创 SVG。

第一星要求完成至少六题且正确率达到 60%；后两星分别依据不同学习项的探索与间隔复习熟练比例。认读和词义两个方向不会把同一项的覆盖率算两次。每轮奖励只领取一次，每日本机日期最多 60 枚贝壳。只有拥有的装饰可摆放，同一件装饰在不同位置之间移动。

进度 schema 为 v2。校验器接受 v1 与 v2；v1 的题目和记忆键保持不变，首次加载前在同一 IndexedDB 中保留原快照。v1 已完成关卡的迁移赠礼每轮五枚贝壳，仅在转换时计算一次。升级快照可从设置导出，重置时一并清除。

## 下一步优先级

1. 自己使用几天，观察提示依赖、片假名混淆、默认每轮新字数和输入耗时。
2. 对照出口仁老师的视频分 P，补充精确的课程映射和待核对清单。
3. 加入可再分发的高质量录音，让长音、促音训练从拍数理解发展成真实听辨。
4. 加入常见混淆字的定向干扰项和更多对比词。
5. 根据实际使用反馈校对新词、例句、难度和干扰项；逐步补充听力与更完整的练习范围，不把当前数量当作完整考试覆盖。
6. 在确有跨设备需求时增加账号与同步。先定义学习事件合并和备份迁移策略，再引入后台。
