ことばの島（语言之岛）首个公开预览版，中文学习界面。

- 假名、N4 目标课程、介护特定技能入门，含学习地图、收藏小屋和备份功能。
- Windows x64 安装版和 Android APK，桌面与应用列表均显示日语名「ことばの島」。
- 每位新玩家从空进度开始，不含作者的游戏记录。
- 修复「五月」等多音词的合成语音输入；安卓使用系统文字转语音。
- Windows 采用系统 WebView2、关闭 GPU 加速并压缩安装包；本机地图静置检查专用内存约 116 MB，具体随设备与场景变化。

在线版：https://taouyh.github.io/kotoba-no-shima/

下载：Windows 使用 `kotoba-no-shima-windows-x64-setup.exe`；安卓使用 `kotoba-no-shima-android.apk`。`SHA256SUMS.txt` 用于校验下载文件。

Windows 使用系统 WebView2，缺少时安装程序会联网下载。当前没有 Windows 商业签名证书，系统可能提示未知发布者。安卓 APK 使用项目固定密钥签名，后续更新保持同一签名。设备需有日语语音包才能朗读；语音音质与能否离线取决于设备。

学习进度只保存在设备本地，网页版与安装版可通过设置页 JSON 备份迁移。课程为基础复习和自主整理的目标学习包，不是官方完整考试题库。
