# 介护特定技能：学习资料桌

目标已按「介护特定技能：介护技能评价＋介护日语评价」整理，区别于介护福祉士国家考试。资料核对日期：2026-10-24。

## 学习路线

1. **日语基础**：继续假名，并学习日常词汇、常见汉字、语法和短文；本游戏 N4 目标课程支持这一阶段。
2. **介护日语**：按术语、会话与声かけ、文书理解三个方向积累表达。本游戏先提供 160 个术语、40 个声かけ表达和 10 道原创文书题。
3. **介护技能**：结合正式教材学习介护基础、身心机制、沟通与生活支援。本游戏的 28 道原创概念题只是入门；现场操作另需正式培训和实训。

N4 并不覆盖介护专业内容；本游戏的地图进度、星星和练习正确率不能当作正式考试合格判定。

核对时，官方考试概要分别列出技能评价 45 题／60 分钟、日语评价 15 题／30 分钟，并列出 2026-04-01 起适用的合格基准：技能 60%、日语 73%。这些信息用于区分备考任务，实际报考时仍应从上面的官方页面重查。游戏中「60% 获得首星」只是探索规则。

## 当前游戏内的内容

| 区域             | 内容                                   |
| ---------------- | -------------------------------------- |
| 认识介护现场     | 人员、场所、设备、计划、报告和基础概念 |
| 身体与状态       | 身体部位、不适、观察相关术语           |
| 生活支援的词语   | 饮食、清洁、更衣、排泄、移动与辅具     |
| 会话与声かけ     | 说明、询问、意愿确认、同事沟通         |
| 记录与交接       | 时间、部位、摄入、本人陈述与观察的理解 |
| 介护基础与沟通   | 尊严、自立、隐私、同意与个别化支援     |
| 观察、报告与安全 | 变化的描述、报告、环境和流程意识       |

词条释义和情境题为本项目整理与编写，没有逐字复制官方教材、音轨或样题。来源标签用于标明学习领域和进一步查阅入口，不表示每一题获得了官方审定。题目不提供诊断、用药或具体操作训练。
