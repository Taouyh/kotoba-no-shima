ことばの島 v0.4.0：内置日语参考音与答对后自动朗读。

- Windows 和安卓安装版自带完整参考音频，不需要玩家安装系统日语语音包，离线也能播放。
- 网页版默认使用同一套音频，首次联网播放后缓存，之后可以离线重听。
- 看字回忆答对后自动播放一次正确读音，切到下一题时停止；保留手动重听按钮，可在设置关闭自动播放。
- 内置音频默认优先，系统声音作为可选项。声音署名：VOICEVOX:四国めたん。
- 应用名仍为「ことばの島」，学习界面保持中文。

在线游玩：https://taouyh.github.io/kotoba-no-shima/

Windows 下载 `kotoba-no-shima-windows-x64-setup.exe`，安卓下载 `kotoba-no-shima-android.apk`。安装版可覆盖升级，保留相同应用 ID 与安卓签名；升级前可在设置导出备份。安装包不包含作者的进度。

Windows 当前没有商业代码签名证书，系统可能提示未知发布者；系统缺少 WebView2 时，安装程序会下载。内置语音为合成参考音，尚未经过日语教师逐条审音，不用来判定声调是否标准。安卓尚需真实手机验收。
